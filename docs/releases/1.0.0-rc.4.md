# Setlist 1.0.0 — candidata 4 (`v1.0.0-rc.4`)

Estado: em andamento. A versão exibida no app permanece `1.0.0` nas três
plataformas. Esta nota acompanha a correção do indicador de atualização e a
habilitação de R8 no Android; não registra uma Release ou builds já publicados.

## Correção prevista

- Encerrar o indicador nativo de refresh que podia ficar preso no iOS ao
  retornar para uma tela depois de edição ou navegação.
- Recriar o `RefreshControl` nativo do iOS nas transições do estado de refresh.
- Manter o indicador automático condicionado a cache expirado (60 segundos),
  com revalidação silenciosa para cache recente e feedback no gesto manual.
- Habilitar R8 com o preset otimizado e redução de recursos nos builds Android
  de release, validar os fluxos críticos e guardar o `mapping.txt` do AAB para
  o `versionCode` enviado.

A correção está na [PR #44](https://github.com/anderson-sillos/setlist/pull/44),
que permanece aberta. A validação foi feita no simulador iPhone 16 Pro, junto a
sete suítes/105 testes, typecheck, ESLint, formatação e `git diff --check`.

## Fechamento da candidata

- [ ] Integrar a PR #44 após revisão e aprovação dos checks obrigatórios.
- [ ] Fixar o commit candidato e registrar a tag `v1.0.0-rc.4`.
- [ ] Gerar o AAB Android com R8, o APK Android de validação, o IPA iOS e a
      exportação Web a partir do mesmo commit.
- [ ] Validar os fluxos críticos no APK Android minificado e guardar o
      `mapping.txt` correspondente ao AAB.
- [ ] Conferir os indicadores DEX e associar o `mapping.txt` à versão correta
      no Play Console.
- [ ] Registrar os identificadores, números de build e estados no manifesto da RC.4.
- [ ] Confirmar o indicador nos artefatos instalados da candidata; o teste no Metro não substitui essa conferência.

Até essas conferências, a correção está prevista para a RC.4, mas não é declarada
como presente nos artefatos distribuídos.
