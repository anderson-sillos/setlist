# Setlist 1.0.1 — candidata 1 (`v1.0.1-rc.1`)

Estado: preparação. A versão do produto é `1.0.1`; `rc.1` identifica a candidata.
A tag será criada após a integração da PR e apontará para o commit usado no build
iOS e na exportação Web.

## Alterações desta candidata

- Os links de download da página Web direcionam diretamente à página oficial do
  Setlist na App Store e ao app Android pelo identificador do pacote.

## Builds e publicação

- O build iOS de produção e o envio ao App Store Connect serão feitos a partir
  do checkout limpo da tag `v1.0.1-rc.1`.
- A Web será exportada do mesmo commit e publicada pelo workflow `Publicar
GitHub Pages`, após a Release candidata e o manifesto serem preparados.
- Não será gerado build Android nesta candidata. A primeira publicação Android
  continua aguardando o processo no Google Play.
- A validação funcional dos links na Web e a revisão do build iOS permanecem
  pendentes.
